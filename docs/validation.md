# 本地验证

验证日期：2026-10-22。

以下为精简发布包之前完成的验证记录；当前发布包不附带测试源码。

本机环境为 Python 3.11.17、PyTorch 2.14.1、PEFT 0.21.2、Diffusers 0.39.0、Transformers 4.57.6、W&B 0.31.0。CPU 测试不下载模型权重。

## 数值对比

直接从原实验源码提取目标优化和 Euler 合成函数作为参考，在 CPU 上比较：

- 40 组目标测试：endpoint/proxy、J1/J2、10 组输入与随机种子；最大绝对误差 0。
- 30 组合成、损失及参数梯度测试：K=1/2/3、10 组输入；三项最大绝对误差均为 0。
- 检查范围为 float32 latent 运算、float64 归一化以及 autograd，不包含真实预训练模型的 GPU 前向。

数值记录见 `reference_comparison.json`。

## 自动测试与检查

- 30 项测试全部通过：信赖域半径、proxy 选择、稀疏梯度解析值、随机流隔离、数据与配置校验、EMA、checkpoint 完整性、模型时间与符号、完整小模型训练、在线评测恢复、固定 PNG 生成、评分续跑、七指标汇总和 W&B 离线记录。
- 实际 PEFT 小模型在保存/恢复后，下一次更新的 adapter 参数、AdamW 状态和 EMA 与连续运行逐位一致。
- 两个 CPU Gloo 进程验证参数广播和梯度平均，包含一个 rank 缺少局部梯度的情况。
- 三组随包配置通过数据计划检查。
- Ruff 静态检查和格式检查通过；CLI 可执行；核心依赖检查通过。W&B 实际离线 run 验证了同一步多组指标、表格、样图和 checkpoint 元数据。
- 源码分发包和 wheel 可构建。交付 ZIP 包含代码、配置、文档、配对计划和提示词。
- 文件名与文本内容均完成命名扫描，未保留被移除的旧方法标识。

## 待服务器验证

当前未连接 GPU 训练服务器，因此没有重新运行完整 Z-Image/HPSv3++ 前向、CUDA/NCCL 八卡训练或历史 checkpoint 的真实模型续训。HPSv3++ 外部源码与权重、ImageReward、Q-Align 和 DeQA 等评测依赖需要在目标环境中配置；本机未加载这些权重。

本版本保持已测试的核心训练数学。在线评测的唯一索引分配和随机噪声方案已明确调整，不能用本机测试结果声称完整历史实验分数逐位复现。
